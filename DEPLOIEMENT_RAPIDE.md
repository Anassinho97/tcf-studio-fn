# TCF Studio sur GitHub : 6 étapes (Darija / français)

1. Sir l GitHub : https://github.com/new
2. Smi repository `tcf-studio`, khallih **Public**, puis **Create repository**.
3. F repository: **Add file > Upload files**. **Décompresse le ZIP** avant : glisse tous les fichiers et le dossier `assets` dans la zone d'upload. Ma t-uploadich le ZIP bohdo.
4. Klik **Commit changes**.
5. **Settings > Pages > Build and deployment** → `Deploy from a branch` → `main` → `/(root)` → **Save**.
6. Ila smitek GitHub hiya `monpseudo`, l'URL ghadi tkoun `https://monpseudo.github.io/tcf-studio/`.

**Important :** Ici l'application est prête à publier, mais elle n'a pas été mise en ligne sur ton compte GitHub. Il faut suivre les étapes ci-dessus.

**Installation sur téléphone :** visite le lien via Safari (iPhone) puis Partager → Sur l'écran d'accueil. Android/PC : bouton Installer s'il apparaît dans Chrome/Edge.
